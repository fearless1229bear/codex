# 每日任务本

一个无需安装依赖的日历任务网页。任务会保存在浏览器的 `localStorage` 中，刷新页面后仍然存在。

## 运行

在仓库目录执行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。

也可以直接双击 `index.html` 打开，但使用本地服务器更接近真实的网站运行方式。

## 功能

- 按日历记录和查阅每天的任务
- 每条任务包含标题和可分段的具体内容
- 添加、编辑、完成和删除任务
- 按全部、待完成和已完成筛选
- 显示每天的任务数量和完成进度
- 自动迁移旧版“今日清单”中的任务
- 自动保存任务到当前浏览器
- 响应式布局，支持手机和桌面浏览器
