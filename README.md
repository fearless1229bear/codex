# 每日任务本

一个无需安装依赖的日历任务网页。登录 Google 账号后，任务通过 Firebase 在不同设备间同步；未登录或暂时断网时仍会保存在当前浏览器中。

## 运行

在仓库目录执行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。

也可以直接双击 `index.html` 打开，但使用本地服务器更接近真实的网站运行方式。

## 功能

- 按日历记录和查阅每天的任务
- 每条任务包含标题和可分段的具体内容
- 添加、编辑、完成和删除任务
- 默认使用完整任务浏览区，按右上角按钮展开添加表单
- 桌面端自动适配浏览器高度，完整页面无需上下滚动
- 按全部、待完成和已完成筛选
- 显示每天的任务数量和完成进度
- 自动迁移旧版“今日清单”中的任务
- 使用 Google 账号登录并通过 Firestore 实时同步
- 首次登录时自动把当前浏览器里的旧任务迁移到账号
- 未登录或同步服务不可用时自动保存在当前浏览器
- 响应式布局，支持手机和桌面浏览器
